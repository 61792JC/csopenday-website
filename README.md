
<h1>HTML project</h1>
<p>Create a single page website for a client.  The page should have an external style sheet (CSS).  The client should be a real person, for example a family member, friend (perhaps your friend is in a band and they would like an online presence to promote themselves?) or a charity for example. The page should be hosted online - there are plenty of free options so look around.
Learning objectives from specification:  1.3.4 Web Technologies (a) HTML, CSS
Supporting Resources:
Craig N Dave HTML video, Craig N Dave CSS video,  https://www.w3schools.com/html, https://www.w3schools.com/css/</p> 
<h2>Mark Scheme</h2>

<p>You will also need to complete a small write up of the project.  Complete the Analysis and Design before you create your Webpage.  These link in to areas you will need to include in your NEA.

You will need to hand in the following:
A Google Doc with the Analysis and Design work completed (see below)
A link to your final website
A copy of the HTML and CSS code used</p>

<h3>Analysis</h3>

<p>Brief
Explain what you have been asked to do and what your webpage will be for</p>

<h4>Research (2 similar webpages)</h4>
<p>Analyse the webpage - fonts / colours links etc
What features / ideas could you take to add to your webpage/website and why
What features / ideas won’t you take?  Explain why</p>

<h5>Success Criteria</h5>
<p>5 or 6 SMART (Specific, Measurable, Achievable, Realistic, Timed) criteria.  E.G

My website will have 4 different CSS classes which it uses, 1 for Main Text, 1 for Titles, 1 for hyperlinks and 1 for subtitles)</p>

<h6>Design</h6>

<p>UI / Plan
Plan your CSS classes and identifiers. (fonts etc)</p>
Sketch a design for the page - what images are you going to use?  What hyperlinks?
Explain how you are making it useable for a range of people
